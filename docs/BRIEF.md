# Project Brief (owner's original instructions, condensed faithfully)

**Goal:** turn one existing generic video of the owner into 10 highly targeted Upwork promo videos that feel
natural, professional, engaging and authentic (not obviously AI). Automate via Claude Code with plain-English instructions.

## Constraints
- Budget $0 ideally. Owner later approved up to about €10 total for clearly worthwhile items; ask before any spend.
- Prefer free, open-source and local or cloud-sandbox tools. No paid APIs unless necessary. Don't assume API credits.
- Never purchase or subscribe. Never incur costs without explicit permission.
- Reuse existing footage. Don't fabricate experience, credentials, results, clients, testimonials or achievements.
- Preserve the owner's real identity and appearance. Don't make the face look synthetic.
- Optimize for conversion and client trust on Upwork, not cinematic effects.

## Phases
1. Research and verify tools (exists, maintained, installable, agent-usable, no hidden paid APIs). Compare the top 3 and recommend one.
2. Inspect the system and set up the project directory. Explain installs and ask permission first. Never expose secrets.
3. Analyze the source footage (duration, resolution, fps, audio, lighting, background, framing, confident sections,
   gestures, awkward pauses, cuts, reusable parts, limitations). Write a report. Never alter the original.
4. 10 concepts: service, customer, pain point, 2-3 s hook, script, CTA, on-screen text, B-roll, style, duration,
   filename. Each meaningfully different. Ask for the gig titles and descriptions first.
5. Editing system: natural pacing, silence removal, clean cuts, subtle zooms, professional captions, hook text,
   B-roll, transitions only where appropriate, legal music only if suitable, strong CTA, consistent branding,
   9:16 or 16:9 as fits, 1080p. No cheap flashy effects.
6. Voice and lip-sync strategy: A) free and realistic (footage + own voiceover + B-roll + captions);
   B) free or low-cost lip-sync (verify limits, watermarks, licensing); C) paid only if clearly better, cost for 10 videos.
   Lip-sync is not the default if it looks less real.
7. Reusable template (hook, talking head, text, B-roll slots, subtitles, CTA, outro), driven by config.
   Ideally: gig title + description in → script, footage selection, B-roll, edit, preview, review, revise, export.
8. Produce video #1 as a proof of concept → owner review → refine → then the remaining 9.
9. QA: clipping, caption errors, typos, awkward cuts, black or frozen frames, aspect ratio, resolution, volume,
   missing assets, CTA, excessive effects, AI artifacts. Contact sheet for quick review.
10. Deliverables: 10 videos, 10 scripts, thumbnails, template, editing scripts, README, report (tools, costs, limits).
    Folders: source/ scripts/ assets/ broll/ templates/ previews/ exports/ reports/

## Working style
Proactive engineer: deliver a working system, research first, keep it simple, don't fabricate tool capabilities,
no irreversible changes, ask only for important decisions, short updates, show real files and previews.
