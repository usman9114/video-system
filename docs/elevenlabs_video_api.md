## Answer: Yes—video generation is available through the public REST API.

It is **not web-app-only**. ElevenLabs documents asynchronous video-generation endpoints, including image-guided generation with Seedance 2.5. The API requires a **Pro plan or above** and an API key with Image & Video or Flows permission. ByteDance models, including Seedance 2.5, are disabled by default and require approval. ([API quickstart](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/image-and-video), [plan and model access](https://elevenlabs.io/docs/overview/capabilities/image-video))

- **Create:** `POST https://api.elevenlabs.io/v1/flows/video`. The Seedance 2.5 model ID is exactly `bytedance-seedance-v2.5`. For an image-guided request, the documented fields include `prompt`, `images`, `duration_secs`, `aspect_ratio`, `resolution`, and `generate_audio`; Seedance 2.5 supports 4–30 seconds, 9:16, and 480p/720p. Its docs say aspect ratio is inferred from a supplied start frame or reference video, so for 9:16 via a still image, use a 9:16 image reference and check how the model handles the ratio. ([Create endpoint and Seedance fields](https://elevenlabs.io/docs/api-reference/flows/video/create.md), [model capabilities](https://elevenlabs.io/docs/overview/capabilities/image-video))

- **Image input:** `images` accepts image references as an uploaded asset, a prior generation, or inline base64 with a MIME type. Reference images and `start_frame`/`end_frame` are mutually exclusive. ([Image reference schema](https://elevenlabs.io/docs/api-reference/flows/video/create.md))

- **Async result:** Create returns an ID with `pending`; poll `GET /v1/flows/video/{generation_id}` until `completed` or `failed`, or provide a configured `webhook`. Video polling should be no more frequent than every 10 seconds; a completed result includes a signed `content_url`. ([Get endpoint](https://elevenlabs.io/docs/api-reference/flows/video/get), [polling and webhooks](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/image-and-video))

- **5-second credit cost / Starter plan:** I could not verify a per-model cost table or Starter-plan API eligibility from the current official docs. ElevenLabs says cost varies by model settings and duration, and matches the app; its API guide says API access requires Pro+, so **Starter is below the documented API minimum**. ([Pricing guidance](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/image-and-video), [API plan requirement](https://elevenlabs.io/docs/overview/capabilities/image-video))

**Veo and Kling:** Veo models are listed in the video API docs. Kling appears in the Image & Video product overview, but I could not verify a corresponding Kling model in the public video-create endpoint’s documented model list. ([Video API model list](https://elevenlabs.io/docs/api-reference/flows/video/create), [product model overview](https://elevenlabs.io/docs/overview/capabilities/image-video))
